## About Me

I'm a developer and **OpenClaw contributor** from **Hangzhou, China**, currently a first-year undergraduate at **Communication University of Nanjing (CUCN)**.

I started exploring **Vibe Coding** in 2025. I enjoy turning everyday needs into practical applications, taking projects from an idea through implementation and deployment while strengthening my programming fundamentals.

## What I Build

My work spans web applications, desktop tools, monitoring dashboards, AI-powered workflows, and animation with Remotion. I use natural language to explore ideas, then refine the results through iteration and hands-on testing.

I'm especially interested in **AI agents and practical software**. I run OpenClaw on my local PC and server to explore how assistants can automate tasks and support everyday development.

## Selected Projects

### [vidown](https://github.com/Jimmy-xuzimo/vidown)

A **cross-platform local video downloader** with a built-in browser for signing in and discovering media. It supports separate video and audio track selection and saving media in its original quality.

### [ciyu-vocab](https://github.com/Jimmy-xuzimo/ciyu-vocab)

A vocabulary-learning app for **web, Windows, and Android**, with eight word books, daily quizzes, spaced review, and progress import/export. The web app supports offline use as a PWA; learning records stay on the device.

### [DSH-for-Android](https://github.com/Jimmy-xuzimo/DSH-for-Android)

DeepSeek Harness on **Android**, with native Material 3 navigation and settings, an on-device Bionic runtime, and integrated Git, Bash, and PTY support.

### [PianoScoreFollower](https://github.com/Jimmy-xuzimo/PianoScoreFollower)

An **Android piano score app** with score import, real-time score following, and automatic page turning.

### Chronos Ecosystem

A **self-hosted personal workspace** connecting calendars, device monitoring, and desktop widgets. The three projects work together, with Agents also usable independently.

| Project | What it does |
| --- | --- |
| [Chronos Monitoring](https://github.com/Jimmy-xuzimo/Chronos-Monitoring) | Web workspace and native Android client for ICS calendars, cloud/NAS/desktop metrics, website certificates, GitHub activity, news, and bookmarks. |
| [Chronos Agents](https://github.com/Jimmy-xuzimo/Chronos-Agents) | Device telemetry for Windows, Linux, macOS, and Android, with authenticated agents, a self-hosted Hub, and Monitoring integration. |
| [Chronos Widgets](https://github.com/Jimmy-xuzimo/Chronos-Widgets) | Native Windows desktop widgets connected to Monitoring, bringing timetables, devices, certificates, and daily information onto the desktop. |
